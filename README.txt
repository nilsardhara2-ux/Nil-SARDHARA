PAYMENT CHECK DEMO — MOBILE WEB APP

આ PWA ફોલ્ડર છે. તેને Android પર Chrome માં Install કરવા માટે વેબસાઇટ HTTPS પર હોવી જરૂરી છે.
માત્ર ZIP ડાઉનલોડ કરવાથી APK બનતું નથી.

મોબાઇલથી પ્રકાશિત કરવાની સરળ રીત:
1. ZIP extract કરો.
2. GitHub પર નવું public repository બનાવો.
3. આ ફોલ્ડરની બધી ફાઇલો repository ના root માં upload કરો.
4. Repository Settings > Pages > Deploy from a branch > main / root પસંદ કરો.
5. મળેલી HTTPS Pages link Android Chrome માં ખોલો.
6. Chrome menu > Install app અથવા Add to Home screen પસંદ કરો.

આ માત્ર demo છે; બેંક/UPI/વાસ્તવિક પેમેન્ટ નથી. Play Store APK/AAB અલગથી બનાવવી અને Play Console review જરૂરી છે.
